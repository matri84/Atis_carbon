⚙️ Core

پوشه core هسته اصلی Backend پروژه است.

تمام قابلیت‌های اصلی مربوط به ارتباط با دیتابیس، Routing، Session، توابع عمومی و تبدیل تاریخ در این بخش قرار گرفته‌اند.

🔧 config.php

این فایل وظیفه نگهداری تنظیمات اصلی پروژه را بر عهده دارد.

در این فایل مواردی مانند:

تنظیمات دیتابیس
پیام‌های خطا
Routeهای پروژه
مسیر صفحات
فایل‌های قابل اجرا

مدیریت می‌شوند.

🗄️ connectio.php

وظیفه این فایل ایجاد اتصال به MySQL با استفاده از PDO است.

اتصال دیتابیس در یک فایل مستقل قرار گرفته تا سایر بخش‌های پروژه بتوانند بدون ایجاد مجدد Connection از آن استفاده کنند.

🛠️ DB.class.php

کلاس اصلی عملیات دیتابیس پروژه است.

متدهای مربوط به عملیات CRUD در این کلاس قرار گرفته‌اند و صفحات پروژه برای کار با اطلاعات دیتابیس از این متدها استفاده می‌کنند.

ساختار این کلاس قابل توسعه است و در پروژه‌های دیگر می‌توان متدهای جدیدی مانند:

Pagination
Search
Filtering
Sorting
Relations

را به آن اضافه کرد.

🧰 function.php

توابع عمومی و پرکاربرد پروژه در این فایل قرار دارند.

برای مثال:

دریافت Header
دریافت Footer
کار با Session
توابع کمکی
عملیات عمومی پروژه

قرار دادن این توابع در یک محل مشخص باعث کاهش تکرار کد در صفحات مختلف شده است.

📅 JalaliDate.class.php

یک کلاس اختصاصی برای کار با تاریخ است.

این کلاس امکان تبدیل تاریخ میلادی به شمسی را فراهم می‌کند و برای نمایش تاریخ‌های پروژه در رابط کاربری مورد استفاده قرار می‌گیرد.

🛣️ سیستم Routing

یکی از قسمت‌های اختصاصی این پروژه، سیستم Routing است.

صفحات سایت داخل پوشه pages قرار دارند و با پسوند:

.atri.php

ذخیره می‌شوند.

برای مثال:

pages/
│
├── home.atri.php
├── about.atri.php
├── services.atri.php
├── contact.atri.php
└── 404.atri.php

Routeهای قابل دسترسی در آرایه $router تعریف می‌شوند.

سپس index.php مسیر درخواست‌شده را بررسی کرده و فایل مربوط به آن Route را اجرا می‌کند.

اگر مسیر وجود نداشته باشد، صفحه:

404.atri.php

نمایش داده می‌شود.

🎯 نقش index.php

index.php نقطه ورود اصلی برنامه است.

تمام درخواست‌ها ابتدا وارد این فایل می‌شوند و سپس بر اساس Route درخواست‌شده، صفحه مناسب انتخاب می‌شود.

به این ترتیب، صفحات پروژه مستقیماً مسئول مدیریت URL و Routing نیستند.

🗃️ Database Layer

ارتباط پروژه با دیتابیس توسط:

PHP
   ↓
PDO
   ↓
MySQL

انجام می‌شود.

منطق مربوط به عملیات دیتابیس نیز در DB.class.php قرار گرفته است.

این جداسازی باعث شده منطق دیتابیس از صفحات سایت جدا باشد و توسعه Backend ساده‌تر انجام شود.

📦 نصب و راه‌اندازی

core/config.php
